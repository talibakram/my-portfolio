## Featured Projects

### 1. Library Management System
A Python-based, console-driven application designed to organize library operations through separate administrator and member workflows. The system uses object-oriented programming and JSON-based persistence to manage books, users, and library-related operations.

### 2. Banking System
A command-line banking application built with Python and object-oriented programming. It demonstrates account management, user authentication, transaction operations, input validation, exception handling, and JSON-based data persistence.

### 3. File Handling Application
A Python project demonstrating Create, Read, Update, and Delete (CRUD) operations on text files, with an emphasis on structured data handling and error management.

### 4. Number Guessing Game
A lightweight Python game in which players attempt to guess a randomly generated number between 1 and 50 within five attempts. It demonstrates conditional logic, loops, random number generation, and basic game-state tracking.

## Getting Started

### Prerequisites
A modern web browser and a code editor are sufficient to explore the portfolio locally.

### Run Locally

1. Clone this repository:
   ```bash
   git clone https://github.com/talibakram/my-portfolio
   ```
2. Open the project folder.
3. Open `index.html` in your browser.

Ensure that `style.css` and the `html_finalprojimages` directory are present in the project folder so the page can load its styling and image assets correctly.
